HSWare Studio v14.2.0 - LightWave Update Center

Update Center redesign
- Published software only. Catalog packages are never queued by LightWave.
- Automatic server-side update monitoring is enabled by default every 6 hours.
- The browser no longer advances software one-by-one with /updates/step calls.
- Update Center opens from stored database results, so already-detected updates appear immediately.
- Manual Check Now starts a server job and only polls progress; closing the tab does not stop the scan.
- Bounded parallel batches (default 4) reduce scan wall time without uncontrolled concurrency.
- Unchanged packages skip CDN file metadata probes; deeper remote metadata probing happens only when a newer version is detected.
- Existing detected updates remain sticky until Mark Updated.
- Update worker is integrated into worker health/reliability monitoring.

Hosting controls
LIGHTWAVE_AUTO_UPDATES=true
LIGHTWAVE_INTERVAL_HOURS=6
LIGHTWAVE_CONCURRENCY=4
LIGHTWAVE_ACTIVE_DELAY_MS=750

Design goal
LightWave uses one-shot timers and sleeps between scheduled checks. There is no permanent polling loop while idle, and it never scans the catalog.
